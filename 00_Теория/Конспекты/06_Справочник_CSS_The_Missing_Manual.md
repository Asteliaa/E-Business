## Краткий конспект по частям

### Введение и Часть I. Основы CSS

- **Разделение ролей.** HTML задаёт структуру и смысл (заголовки, абзацы, списки), CSS — внешний вид. Пример автора: одинаковая по дизайну страница весит 4 КБ и 71 строку с CSS против 14 КБ и 213 строк на «чистом» HTML.
- **HTML5.** Короткий `<!doctype html>` обязателен: без doctype браузеры по-разному отображают CSS. Семантические элементы: `header`, `nav`, `footer`, `article`, `aside`.
- **Анатомия стиля (правила):** `селектор { свойство: значение; }`. Селектор выбирает элементы, блок объявлений описывает оформление. **Таблица стилей** — набор правил: внутренняя (`<style>` в `head`) или внешняя (файл `.css` через `<link>`). Для сайта рекомендуется внешняя: один файл на все страницы, кешируется браузером.
- **Селекторы:**
  - селекторы тегов (`p`, `h1`), классы (`.name`, многократно), идентификаторы (`#id`, один на странице), группы (`h1, h2`), селекторы потомков (`.gallery img`);
  - псевдоклассы ссылок `:link`, `:visited`, `:hover`, `:active`, а также `:focus`;
  - псевдоэлементы `::first-letter` и `::first-line` (в CSS3 двойное двоеточие отличает их от псевдоклассов);
  - селекторы атрибутов, дочерние (`>`), дочерние псевдоклассы (`:first-child`, `:nth-child`…), родственные (`+`, `~`), `:target`, `:not()`.
- **Наследование.** Часть свойств (прежде всего текстовые: шрифт, цвет) переходит от предков ко всем потомкам. Удобно задавать шрифт на `body` или раздел страницы. Ограничения: не наследуются, например, границы, поля, отступы и фон. У наследованных свойств нет специфичности.
- **Каскадность** — правила, по которым решаются конфликты стилей:
  - унаследованные стили объединяются;
  - при конфликте побеждает **более специфичный** селектор. Упрощённая формула автора: тег = 1, класс или псевдокласс = 10, id = 100, инлайн-стиль выше; составные селекторы суммируются (`#banner .byline` = 110);
  - при равной специфичности побеждает **последний** объявленный стиль;
  - `!important` перебивает обычный порядок;
  - для отладки — инспектор браузера («Исследовать элемент»);
  - сброс браузерных стилей (reset или Normalize) делает старт предсказуемым.

### Часть II. Применение CSS

- **Типографика (гл. 6).**
  - `font-family` и стеки шрифтов, веб-шрифты через `@font-face`, сервис **Google Fonts**;
  - цвет в форматах hex, RGB/RGBA, HSL; размеры в `px`, `em`, `rem`, `%`;
  - межстрочный интервал, выравнивание, отступ первой строки, трансформация регистра, `text-shadow`, форматирование списков;
  - совет автора: мало шрифтов и чёткая иерархия размеров.
- **Блочная модель (гл. 7)** — одна из важнейших тем книги:
  - каждый элемент — прямоугольник из контента, `padding` (внутренний отступ), `border` (граница) и `margin` (поле, внешний отступ); `background-color` заполняет область до границы;
  - схлопывание вертикальных полей, блочные и строчные элементы (`display`), `width` и `height`, `max-width`;
  - **`box-sizing: border-box`**: ширина считается с учётом отступов и границ;
  - `border-radius`, `box-shadow`, `overflow`, `float` и `clear` для обтекания.
- **Графика (гл. 8).**
  - `img` оформляется общими свойствами (`border`, `padding`, `float`, `margin`, `border-radius: 50%` для круглого фото). Лучше через классы, а не селектор тега;
  - фоны: `background-image`, `-repeat`, `-position`, `-attachment`, `-size`, сокращённая запись `background`, **множественные фоны**, **линейные и радиальные градиенты**.
- **Навигация (гл. 9).**
  - состояния ссылок (`:link`, `:visited`, `:hover`, `:active`, `:focus`), ограничения `:visited` ради приватности;
  - горизонтальные и вертикальные панели навигации из списков `ul`/`li`, кнопки, ролловеры без JavaScript;
  - оформление ссылок по типу (внешние, e-mail, PDF) через селекторы атрибутов.
- **Анимация (гл. 10).**
  - `transform`: `rotate`, `scale`, `translate`, `skew`, `transform-origin`. Преобразование не сдвигает соседние элементы;
  - `transition`: плавная смена значений при `:hover` и т. п., с длительностью, задержкой и функцией времени;
  - `@keyframes` и `animation` — многошаговая анимация;
  - вендорные префиксы (`-webkit-`, `-ms-`) и инструмент Autoprefixer.
- **Таблицы и формы (гл. 11).**
  - таблицы только для **данных**, а не для раскладки;
  - оформление `th`/`td`, чередование строк (`:nth-child`), `border-collapse`;
  - стилизация полей, кнопок и меток форм, подсветка активного поля через `:focus`.

### Часть III. Вёрстка страниц с помощью CSS

- **Типы макетов (гл. 12):**
  - **фиксированный** (часто 960 px) — полный контроль, но плохо на телефонах;
  - **резиновый** (ширина в %) — заполняет окно, но длинные строки на больших экранах;
  - **адаптивный** — меняет раскладку под ширину экрана.
  
  Принцип CSS-вёрстки: обёртки-контейнеры (`div` или семантические элементы HTML5), колонки, стратегия «сначала структура HTML, потом раскладка».
- **Float-макеты (гл. 13)**, на 2015 г. самый распространённый метод:
  - колонки через `float: left/right` и `width` в %;
  - важен порядок кода: обтекаемый элемент идёт раньше;
  - типичные проблемы: «выпадение» из контейнера, clearfix, выравнивание высоты колонок;
  - практикум по многоколоночным макетам.
- **Позиционирование (гл. 14):**
  - `position`: `static`, **`relative`** (сдвиг относительно своего места, «дыра» остаётся; главное назначение — точка отсчёта для вложенных абсолютных элементов), **`absolute`** (вне потока, координаты `top`/`right`/`bottom`/`left`), **`fixed`** (закреплён на экране, например «липкая» панель навигации);
  - `z-index` для наложения;
  - нельзя сочетать `float` с абсолютным или фиксированным позиционированием;
  - типовые приёмы: подпись поверх фото, логотип в шапке.
- **Адаптивный веб-дизайн (гл. 15)**, термин Итана Маркотта. Три опоры:
  1. **гибкие сетки** (ширины в %);
  2. **гибкие изображения** (`max-width: 100%`);
  3. **медиазапросы** `@media (min-width: …)`.
  
  Обязательный `<meta name="viewport" content="width=device-width">`, иначе мобильный браузер уменьшает страницу. Стратегии: менять число колонок, убирать `float` на узких экранах, уменьшать заголовки и поля, переделывать навигацию. Подходы desktop-first и **mobile first**.
- **Модульная сетка Skeleton (гл. 16):**
  - сетка — строки и столбцы одинаковой ширины, обычно **12 столбцов** (делятся на 2, 3, 4);
  - HTML размечается классами `container` / `row` / `columns`;
  - готовая адаптивная сетка с подключением собственного `custom.css` в стиле mobile first.
- **Flexbox (гл. 17)** — новый на тот момент метод:
  - `display: flex` превращает элемент во flex-контейнер;
  - свойства контейнера: `flex-direction`, `flex-wrap` (или `flex-flow`), `justify-content` (по главной оси), `align-items` и `align-content` (по поперечной);
  - свойства элементов: `order`, `align-self`, **`flex`** (`flex-grow`, `flex-shrink`, `flex-basis`);
  - плюсы: равные по высоте колонки, кнопки «прижаты» к низу карточек, меньше кода, чем с float;
  - поддержка на 2015 г.: IE10+ (частично), Edge, Chrome, Safari, Opera, Firefox.

### Часть IV. Профессиональные приёмы

- **Организация CSS (гл. 18):**
  - комментарии `/* … */`, в том числе шапка файла с версией и авторством;
  - понятные имена классов, группировка стилей по разделам (базовые, раскладка, компоненты);
  - несколько таблиц стилей, сброс или Normalize для устранения браузерных различий;
  - осмысленное использование селекторов потомков, чтобы не плодить классы.
- **Sass (гл. 19)** — препроцессор: код `.scss` компилируется в `.css`. В книге ставится через Ruby и командную строку.
  - фрагменты (`_partial.scss`) и `@import` — стили в маленьких файлах, на выходе один сжатый CSS;
  - **переменные** (`$brand-color`) — корпоративные цвета меняются в одном месте;
  - **вложенные селекторы**, `&`;
  - **`@extend`** (наследование свойств);
  - **примеси** `@mixin` / `@include` с аргументами, в том числе для вендорных префиксов;
  - медиазапросы внутри правил;
  - **source maps** для отладки в инспекторе.

**Ограничения книги (учесть при использовании):** она 2015 года. В ней нет **CSS Grid**, CSS-переменных, `gap` для flexbox и современных единиц вроде `clamp()`. Поддержка браузеров описана для старых IE, и вендорные префиксы сейчас в основном не нужны. Для двумерной раскладки экранов IDE лучше дополнительно смотреть актуальную документацию (MDN) по Grid. Основы (селекторы, каскад, блочная модель, позиционирование, flexbox, медиазапросы) остаются актуальными.

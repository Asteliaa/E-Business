## 5 Макросы VBA (по желанию)

Файл `VBA/LR1_XLT_Trend_Seasonality.bas`: открыть рабочую копию шаблона (например, `Excel/XLT_ОСНОВНОЙ_UML_BY.xlsx`), Alt+F11 → File → Import File → выбрать .bas, затем Alt+F8: `ImportInputCsv` (загрузка CSV из `Материалы_собранные/GT_Беларусь/XLT_ввод_данных_*.csv`), `ShowSummary` (сводка Панели и Деловых_циклов), `KeepOnlySource` (вариант «только GT» / «только Вордстат», делать на копии книги), `CheckErrors` (поиск ячеек «#…»). Для запуска макросов может понадобиться разрешить их в Центре управления безопасностью Excel; книгу с макросом сохранять как .xlsm.

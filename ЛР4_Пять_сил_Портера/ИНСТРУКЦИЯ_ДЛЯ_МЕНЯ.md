# ЛР4. Инструкция для студентки

## Что нужно сделать лично (решение Р-10)
1. Новые запросы Вордстата (если нужны помимо ядра ЛР1): нужен ваш логин.
2. CPC и конкурентность PPC: Google Ads Keyword Planner или Яндекс Директ (прогноз бюджета), нужен рекламный аккаунт. Без них лист 04 (столбцы E, F) остаётся без данных.

Полный реестр: Python\from_prev_labs.py (запуск: python Python\from_prev_labs.py). Главное: окончательная формулировка рынка и границ (ЛР1); один снимок Similarweb одной датой с долями Беларуси, итоговый диапазон объёма рынка, ценовой коридор, число клиентов, курс НБРБ (ЛР2-3).

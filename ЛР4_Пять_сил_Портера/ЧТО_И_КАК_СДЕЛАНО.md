# ЛР4. Что и как сделано

## Excel
- Рабочая копия: Python\00_make_workcopy.py открывает оригинал шаблона через Excel (COM) с параметром восстановления и сохраняет как Excel\ocenka_konkurencii_NotaCode.xlsx. Оригинал не менялся; через openpyxl файл не пересохранялся (иначе пропадает диаграмма листа 08).
- Python\01_prepare_workcopy.py: исправления Д2 (01 B8–B10), Д3 (05 B38), Д4 (06 B38), Д6 (07 E13 = SUM), очистка демоданных, перечень 20 кандидатов на листах 02, 05, 06 (один список, Д15), запросы ядра на листе 04, строки Вордстата, Google Trends, GitHub, сайтов конкурентов на листе 09, пометки об отсутствии данных на листах 01 и 08 (Д18).
- Особенность Excel: включено автозаполнение формул в списках, оно протягивало формулы на лишние строки. В Python\xl_com.py оно отключается на время работы и возвращается обратно.
- Значения «до/после» исправлений получены на демоданных шаблона: Python\demo_check.py (временная копия вне проекта).

## Python
- lr4_calc.py: формулы листов 02–07 как в шаблоне (основной расчёт), вариант Word (сырые визиты, лидеры топ-3/топ-5, простое среднее 8 критериев, матрица А по 6 и 5 строкам), справочный индекс с делением на сумму весов.
- lr4_io.py и data\*.csv: входные таблицы; «пусто» или значение с 🔲 означает отсутствие данных.
- 03_apply_to_excel.py: перенос CSV в Excel и протяжка формул только на строки с полными данными (Д5).
- 04_verify.py: расчёт по тем же CSV и сверка с ячейками Excel.
- selftest.py: проверка конвейера на синтетических данных во временной папке (все значения совпали).
- from_prev_labs.py: реестр заглушек ЛР1/ЛР2-3 и список данных для сбора в ЛР4.
- 05_figures.py: рисунки; 06_build_report.py: сборка ОТЧЕТ.md из Python\report_body.tmpl (нумерация таблиц, карточки, реестр).

## Отчёт
Структура: 1 Цель; 2 Ход (2.1–2.12); 3 Проверка по критериям методики; Выводы; Список источников; Приложения А–Г. Все числа ЛР1/ЛР2-3 и результаты оценок — заглушки 🔲 с кодами реестра. Docx: python -B _tools/build_lab_docx.py ЛР4 (из E:\ИИТ\ЭлектронныйБизнес).

## Порядок подстановки данных
1. Заполнить Python\data\*.csv (реестр from_prev_labs.py).
2. python Python\03_apply_to_excel.py, затем python Python\04_verify.py.
3. Внести баллы в word_criteria.csv, matrix_a.csv, matrix_b.csv; заполнить 🔲 в Python\report_body.tmpl; python Python\06_build_report.py.
4. Скриншот листа 08 в Скриншоты\; пересобрать docx; set_office_meta.py.

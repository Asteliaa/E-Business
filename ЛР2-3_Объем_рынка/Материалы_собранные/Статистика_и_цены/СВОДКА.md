# СВОДКА: статистика и цены (дата обращения 30.09.2026)

Таблица значений: `СВОДКА_статистика.csv` (разделитель `;`, UTF-8 с BOM). Сырьё: `raw/` (статистика, курсы) и `raw_prices/` (тарифы). Цены даны как на страницах, без пересчёта.

- Студенты УВО РБ 2025/26: 229,0 тыс. (дневная 160,5; заочная 67,8; дистанционная 0,6), 2024/25: 224,2; вузов 47; ППС 17,1 тыс.; магистрантов 10,7 тыс. Подтверждено по сборнику «Образование в РБ, 2026» (PDF сохранён).
- Организации цифровой экономики: 8533 (2024), из них сектор ИКТ 5462. Подтверждено по digital_economy-2024.xls (файл сохранён). Работники цифровой экономики 130 549, сектора ИКТ 104 381; з/п сектора ИКТ 5661,8 BYN (2024).
- Средняя з/п по РБ: 3172,0 BYN (июль 2026), 2960,7 (янв.-июль); реальные доходы населения 108,1 % к янв.-июлю 2025 (экспресс-информация Белстата за янв.-авг. 2026).
- «Информация и связь»: 6413 BYN (июль 2026), 6190,4 (июнь) - только вторичный источник (myfin.by со ссылкой на Белстат).
- Базовая величина 45 BYN с 01.01.2026 (постановление Совмина № 651).
- Стипендии с 01.02.2026 (вторичный источник teenage.by): БГУ 208,61-312,92 BYN, БГУИР ИТ 224,66-342,34 BYN, социальная 128,38 BYN. Размеры зависят от вуза.
- ПВТ: более 1000 резидентов, порядка 60 тыс. работников (страница без даты, данные за 2025); 31 новый резидент одобрен 18.09.2026.
- МСП на 01.01.2026: 135 тыс. организаций, 204,4 тыс. ИП.
- Интернет: 94,3 % населения 6-72 лет (Белстат, 2024); 8,47 млн пользователей, 94,3 % (DataReportal, октябрь 2025).
- Тарифы: Lucidchart, Miro, Mermaid Chart, Visual Paradigm Online, Creately, Eraser, Whimsical, dbdiagram.io, draw.io, PlantUML, Visio Plan 1/2.

- Студенты по группам специальностей (ИТ, экономика, управление) и число преподавателей ИТ-направлений: в сборнике нет разбивки; edustat.by не открылся. Нет данных (30.09.2026).
- Занятые в экономике по видам деятельности «информация и связь» и «профессиональная, научная и техническая деятельность»: нет данных (есть только списочная численность сектора ИКТ за 2024 г.).
- Номинальные денежные доходы населения на душу: нет данных.
- Первичные акты о размерах стипендий (учебная, социальная) не найдены; цифры из вторичного источника.
- Первичная таблица Белстата с з/п по видам деятельности не получена (dataportal.belstat.gov.by - SPA); использован myfin.by.
- Точное число резидентов ПВТ на сайте не указано (только «более 1000»).
- Зарплаты ИТ по dev.by: нет данных (salaries.devby.io вернул 502; свежих обзоров с медианами по ролям не найдено).
- Цены при помесячной оплате не захвачены для Lucidchart, Miro, Mermaid Chart, Visual Paradigm Online, Whimsical (на странице видна цена при годовой оплате). Помесячные цены есть для Eraser, dbdiagram.io, Creately Starter.
- Visual Paradigm Online: заданные тарифы Modeler/Personal/Standard/Professional на странице заменены на Starter/Advance/Combo/Deluxe. Creately: URL /pricing/ возвращает 404, рабочий адрес /plans/. Lucidchart отдаёт 403 на curl, данные сняты через браузер.
- Скидки для студентов: Miro (бесплатно по Education Plan), Whimsical (бесплатно по заявке), Eraser и Creately (скидка без суммы); у Lucidchart не указана.

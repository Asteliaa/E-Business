## 2. М1: оценка объёма рынка по данным Similarweb

**Назначение.** Пошаговая методика оценки объёма цифрового рынка по данным Similarweb и связанных выгрузок. Применяется **после** анализа интереса аудитории, семантического ядра и фиксации границ. Similarweb — инструмент цифровой рыночной разведки, а не бухгалтерский источник выручки; объект анализа — цифровое присутствие (домен, приложение, категория, канал, запрос).

**Итоговый результат:** паспорт цифрового рынка, таблица конкурентов, расчёт посещаемости сегмента, география спроса, канальная структура, оценка достижимой выручки, вывод о перспективности.

### 2.1. Что измеряет Similarweb (разд. 2)

| Блок данных | Что показывает | Использование |
|---|---|---|
| Трафик и вовлечённость | Визиты, уникальные посетители, длительность, страниц/визит, отказы, динамика | Цифровой масштаб рынка, сила игроков |
| Доли трафика | Доля сайта/канала/ключевого слова в конкурентной группе | Концентрация, сила лидеров, достижимая доля |
| География | Трафик по странам/регионам | Географические границы, приоритетные территории |
| Маркетинговые каналы | Direct, Search, Paid, Referral, Social, Mail, Display | Где конкуренты получают аудиторию |
| Поиск и ключевые слова | Запросы, поисковые визиты, органика/платный, позиции, CPC, сложность | Коммерческий спрос, стоимость входа в поиск |
| Реферальный трафик | Входящие/исходящие источники | Партнёры, каталоги, площадки |
| Социальный трафик | Соцсети-источники | Роль контента |
| Демография | Возраст, пол | Уточнение сегментов |
| Категории и рейтинги | Лидеры категории, ранги | Рынок как совокупность игроков |
| Сегменты сайта | Трафик разделов/папок | Выделение нужной бизнес-линии |

### 2.2. Ограничения (разд. 3)

Малый трафик → выше погрешность; трафик ≠ продажа/заявка; разные модели монетизации; **суммирование визитов конкурентов завышает аудиторию** (один пользователь посещает несколько сайтов); для локальных рынков нужна сверка с Вордстатом, GT, статистикой, рекламными кабинетами; доступность отчётов зависит от тарифа.

### 2.3. Общая схема (разд. 4, 10 шагов)

1 границы → 2 конкуренты и цифровые заменители → 3 период, страна, устройство, тип трафика (единые) → 4 трафик и вовлечённость → 5 доли и география → 6 каналы и поиск → 7 **объём цифрового рынка и концентрация (суммарный трафик, доли, CR3/CR5, HHI)** → 8 трафик → продажи (конверсия, чек) → 9 проверка другими источниками → 10 вывод.

### 2.4. Что можно выгружать (разд. 5)

- **Интерфейс:** XLSX (основной формат расчётов), CSV, PDF (приложение к отчёту), PNG (графики), ссылка на отчёт.
- **Data Exporter:** домены (трафик, динамика, вовлечённость, страна, устройство, период), география, каналы, поисковые данные (визиты, доля ключа, органика/платные, URL и позиции, CPC, объём, сложность), рефералы, приложения, массовая загрузка ключевых слов.
- **API и потоки:** REST API (автоматизация), Batch API (много доменов/периодов), Data Feeds (крупные наборы для собственного хранилища), Scheduled reports (выгрузки по расписанию).
- **E-commerce модули:** категории товаров, SKU, ключевые слова розницы, бренды, экспорт больших списков.
- Фиксировать не только значение, но и **способ выгрузки** (интерфейс / отчёт / Data Exporter / API / Data Feeds / модуль).

### 2.6. Формулы М1 (разд. 7)

- **Формула 1.** Объём цифрового трафика рынка = Σ визитов всех релевантных сайтов конкурентного набора за период.
- **Формула 2.** Доля сайта = визиты сайта / суммарные визиты набора × 100 %.
- **Формула 3.** SAM по трафику = суммарные визиты набора × доля трафика из выбранной страны/региона.
- **Концентрация (7.2):** CR3 = доля 1-го + 2-го + 3-го игрока; CR5 = сумма долей пяти крупнейших; HHI = Σ квадратов долей в процентах. Название — «концентрация цифрового внимания/трафика», а не выручки. Интерпретация: низкая (много сопоставимых игроков → нишевание, SEO, контент), средняя (несколько сильных → специализация и канал), высокая (лидеры собирают значительную часть → сильное отличие, партнёрства, платное продвижение, узкий сегмент).
- **Канальный SAM (7.3):** доступный трафик канала = суммарный трафик рынка × доля канала × достижимая доля нового бизнеса в канале. Интерпретация каналов: Direct — барьер узнаваемости; Organic — спрос через поиск; Paid — бюджет входа; Referrals — партнёрства; Social — контент-план; Display — бюджет узнаваемости; Email — зрелость удержания.
- **Поиск (7.4):** потенциальная выручка из поиска = поисковые визиты по коммерческим запросам × доля достижимого трафика × конверсия в заявку × конверсия в продажу × средний чек. Группы: коммерческие, проблемные, брендовые конкурентов, категорийные, локальные.
- **Воронка (7.5):** выручка = трафик × достижимая доля × конверсия в заявку × конверсия в продажу × средний чек × число покупок за период.

Сценарные ориентиры М1 (7.5):

| Показатель | Осторожный | Базовый | Оптимистичный |
|---|---|---|---|
| Достижимая доля трафика рынка | 0,1–0,5 % | 0,5–2 % | 2–5 % |
| Конверсия визита в заявку | 0,3–1 % | 1–3 % | 3–7 % |
| Конверсия заявки в продажу | 5–15 % | 15–30 % | 30–50 % |
| Средний чек | низкая оценка | реалистичная | верхняя |
| Повторные покупки | нет/редко | частично | регулярно |

### 2.9. Итоговая модель М1 (разд. 11) — TAM/SAM/SOM цифрового внимания

| Уровень | Формула | Что показывает |
|---|---|---|
| **TAM цифрового внимания** | Суммарный трафик всех релевантных сайтов категории за период | Общий цифровой масштаб темы |

| Проверка конкурентами | Средняя выручка конкурента × число активных конкурентов | Внешняя проверка через предложение |
| Проверка поиском | Коммерческие поисковые визиты × доля × конверсия × чек | Проверка через активный спрос |

### 2.10. Контроль качества и ошибки (разд. 12–13)

Контрольные вопросы: список конкурентов соответствует границам; нет сайтов с другой клиентской задачей; единые период/страна/устройство/тип трафика; разделены общий, страновой и канальный трафик; доля трафика не подменяет долю выручки; проверены выбросы и сезонность; информационные запросы отделены; три сценария; сверка с GT, Вордстатом, статистикой, ценами, рекламой; указаны ограничения.

Типовые ошибки: трафик = рынок; суммирование без проверки границ; разные фильтры; игнорирование малых сайтов; прямой трафик считать доступным новому игроку; брендовые запросы = общий спрос; игнорирование международного трафика; один точный расчёт.

## 3. М2: оценка рынка на основе данных Similarweb

**Главная задача** — не переписывать посещаемость, а построить цепочку: *сайты конкурентов → суммарный трафик сегмента → релевантная аудитория → заявки/заказы → денежный объём рынка*. Бесплатный Website Traffic Checker даёт посещаемость, вовлечённость, источники трафика, ключевые слова, рефералы, рекламу, технологии и похожие сайты; Data Exporter, API и Batch API зависят от подписки и **data credits**.

### 3.1. Базовая расчётная цепочка (разд. 3)

1. Суммарный трафик сегмента = Σ посещений выбранных конкурентов.
2. Географически релевантный трафик = суммарный × доля страны/региона.
3. Коммерчески релевантный трафик = географический × доля каналов/страниц, связанных с покупкой.
4. Потенциальные заявки = коммерческий трафик × конверсия посещение → заявка.
5. Потенциальные продажи = заявки × конверсия заявка → оплата.
6. Объём рынка = продажи × средний чек.
7. Годовой объём = месячный × 12 или сумма месячных оценок.

Сценарный расчёт (осторожный / базовый / оптимистичный) обязателен.

### 3.2. Границы и выборка (разд. 4–5)

Границы: продуктовые, клиентские, географические, канальные, **семантические**, границы заменителей. Группы сайтов: прямые конкуренты, крупные цифровые игроки, платформы и каталоги, заменители, информационные ресурсы (только если конвертируют трафик). **Минимум 5–10 сайтов**, для устойчивой оценки **15–30**; во фрагментированном рынке — группы «лидеры / средние / нишевые».

Карточка сайта (разд. 6): домен, тип игрока, территория, период, посещения, динамика, вовлечённость, география, каналы, запросы, похожие сайты, комментарий исследователя. Сводная таблица (разд. 7): домен | тип | посещения/мес. | доля географии | релевантные посещения = посещения × доля | доля в выборке = релевантные / сумма | комментарий.

### 3.3. Расчёт 1 — цифровой объём аудитории (разд. 8)

- **V_sample** = сумма посещений сайтов конкурентной выборки;
- **V_geo** = V_sample × средняя или индивидуальная доля трафика выбранной географии;
- **V_total = V_geo / коэффициент охвата выборки**, где коэффициент охвата — какую часть рынка, по оценке исследователя, покрывают выбранные сайты.

| Коэффициент охвата выборки | Когда применять | Интерпретация |
|---|---|---|
| 0,80–0,90 | Выборка включает почти всех заметных конкурентов | Оценка плотная, корректировка небольшая |
| 0,60–0,75 | Учтены основные игроки, часть нишевых неизвестна | Типовая ситуация предварительного анализа |
| 0,40–0,55 | Рынок фрагментирован, много малых исполнителей и соцканалов | Осторожность, широкий диапазон |
| ниже 0,40 | Выборка слабая или рынок плохо представлен сайтами | Только разведочный ориентир |

### 3.4. Расчёты 2–4 — денежный объём (разд. 9–11)

- **Сервисная модель:** лиды = релевантные посещения × конверсия в заявку; продажи = лиды × конверсия в оплату; месячный объём = продажи × чек; годовой = сумма или × 12; для повторной услуги: клиенты × месячный платёж × средняя длительность обслуживания.

| Параметр | Осторожный | Базовый | Оптимистичный |
|---|---|---|---|
| Конверсия посещения в заявку | 0,2–0,5 % | 0,5–1,5 % | 1,5–3,0 % |
| Конверсия заявки в оплату | 5–10 % | 10–25 % | 25–40 % |
| Средний чек | минимальный пакет | типовой | расширенный |
| Коэффициент охвата выборки | 0,40–0,55 | 0,60–0,75 | 0,80–0,90 |
| Итог | нижняя граница | рабочая оценка | верхняя граница |

- **Интернет-магазин:** покупки = релевантные посещения × конверсия в покупку; объём = покупки × чек; годовой — с учётом сезонности; с повторами: покупатели × чек × покупок в год.
- **Платформа:** GMV = сделки × средняя сумма; выручка = GMV × комиссия; альтернативно — платные продавцы × подписка + реклама + комиссии. Трафик SW — для масштаба аудитории и доли платформы.

### 3.5. Расчёт 5 — доли и концентрация (разд. 12)

- Доля трафика сайта = релевантные посещения сайта / Σ релевантных посещений выборки;
- **HHI по трафику = Σ (долей)² × 10 000** (то же, что Σ квадратов долей в процентах).

| HHI по трафику | Интерпретация |
|---|---|
| **до 1 500** | Низкая концентрация: трафик распределён между многими игроками |
| **1 500–2 500** | Умеренная: есть заметные лидеры, но рынок не закрыт |
| **выше 2 500** | Высокая: несколько игроков удерживают значительную часть цифрового внимания |

Это «оценка концентрации трафика», а не рыночной власти (нужны выручка, клиенты, цены, барьеры, заменители).

### 3.6. Каналы, география, поиск (разд. 13–15)

- Каналы: Direct — узнаваемость, лидеров трудно догнать; Search — нужны ядро, SEO, реклама; Referrals — партнёрства, каталоги; Social — контент, сообщества; Display — рекламный бюджет; Email — удержание.
- **Расчёт 6:** трафик территории = трафик сайта × доля страны; трафик территории по рынку = Σ по выборке; сайт с низкой долей территории не должен сильно влиять на локальный рынок. Ситуации: у большинства высокая доля страны → граница подтверждена; трафик международный → расширить рынок или искать локальных; крупный международный доминирует при малой локальной доле → учитывать как заменитель, не завышать; локальные малые с высокой релевантностью → важны для доступного рынка.
- Запросы: общий тематический, проблемный, коммерческий (главный для платёжеспособного спроса), локальный, брендовый (сила конкурента, не весь спрос).

### 3.7. Сценарный расчёт (разд. 16) и пример (разд. 17)

| Показатель | Осторожный | Базовый | Оптимистичный |
|---|---|---|---|
| Коэффициент охвата выборки | 0,45 | 0,65 | 0,85 |
| Коммерчески релевантная доля трафика | 20 % | 35 % | 50 % |
| Географическая релевантность, конверсия, чек | низкие | средние | высокие |

Пример «маркетинг»: 10 сайтов × 120 000 визитов/мес.; 55 % из Беларуси → 66 000; охват 65 % → 101 538; коммерческая доля 35 % → 35 538; конверсия 1 % → 355 заявок; оплата 20 % → 71 сделка; чек 800 BYN → 56 800 BYN/мес.; **681 600 BYN/год**.

### 3.8. Контроль, бесплатный доступ, итоговый вывод (разд. 18–23)

Контроль: единый период; сайты относятся к рынку; учтены заменители; география не смешана; брендовый трафик отделён; перепроверка; все допущения записаны. Бесплатный доступ: вручную (карточка, скриншот, дата), итог — «предварительный диапазон». Итоговый вывод из 7 элементов: границы рынка; конкурентная база; цифровой масштаб; структура спроса; расчётный объём «от … до … в год»; ограничения; следующий шаг. Рабочий журнал: дата | источник | данные | период | что взято | ограничение. Краткий алгоритм — 9 шагов.

## 5. Расхождения между методиками и шаблоном

1. **Направление коэффициента охвата по сценариям.** М2 (разд. 9, 16) ставит в осторожный сценарий *низкий* охват (0,40–0,55 / 0,45), а в оптимистичный — *высокий* (0,80–0,90 / 0,85). Так как V_total = V_geo / охват, это **увеличивает** рынок в осторожном сценарии. Шаблон `metodika_ocenki_obema_rynka_po_similarweb.xlsx` (`06_Воронка_сценарии`) делает наоборот: 0,8 / 0,7 / 0,55. В работе по NotaCode принята логика «осторожный = меньший рынок»: **0,80 / 0,60 / 0,45**; противоречие описано в отчёте.
2. **Доля коммерческой релевантности.** В М2 есть множитель 20/35/50 %, в шаблоне — нет (и нет столбца «доля релевантности», хотя `00_Методика` его упоминает). Поэтому шаблонный «рынок/год» выше, чем расчёт по М2; в работе показаны оба.
3. **Ошибка шаблона:** `'01_Параметры'!B9/B10` суммируют `G5:G24`/`H5:H24`, теряя строку 4. Исправляется модулем `VBA/NC7_ObemSW.bas`.
4. **CR5 при выборке < 5 сайтов** равен CR4 (в NotaCode — 4 домена).

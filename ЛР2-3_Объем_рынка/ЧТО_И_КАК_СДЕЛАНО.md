# ЛР2-3 — что и как сделано

## Кратко
Оценён объём рынка NotaCode в Беларуси девятью методиками (поисковый спрос, Similarweb в трёх вариантах, «сверху вниз» / «снизу вверх», потенциальные клиенты, воронка, маркетплейсы, сценарии, платёжеспособность) на семи Excel-шаблонах. Каждый расчёт выполнен по Excel-шаблону (основной) и по тексту методики (вариант Word), расхождения показаны. Итог диапазоном на двух уровнях: доступный рынок (SAM) по клиентской базе 60–498 тыс. BYN в год (базовая 238 тыс. BYN, около 78 тыс. USD), достижимая выручка первого года 0,3–19,9 тыс. BYN; оценки по трафику Similarweb и поисковому каналу ниже на порядки (ограничения и причины — в разделе 2.10 отчёта). Часть данных не получена и помечена «ДОСНЯТЬ»: Similarweb по большинству доменов (лимит бесплатного доступа), опрос, рекламные кабинеты.

## Подробно

### Данные (Материалы_собранные\)
- Вордстат (Беларусь, id 149): Топы 25.08–23.09.2026 и помесячная Динамика (сентябрь 2024 – август 2026) по 20 запросам ядра, заменителям и AI-запросам; ~30 формулировок для групп «коммерческие / проблемные / инструментальные»; вкладка «Регионы» по plantuml. Сняты через внутренние запросы страницы (getTable, getGraph) под учётной записью пользовательницы, сырьё — в JSON. Операторы группировки в «Динамике» не работают, поэтому групповые ряды суммируются по формулировкам; ряды с нулями при ненулевых Топах исключены (объяснение в отчёте).
- Google Trends: один запрос из четырёх терминов (UML, BPMN, PlantUML, IDEF0), Беларусь, 12 месяцев, единая шкала; данные крайне разрежены (19 из 53 недель ненулевые).
- Similarweb: полностью снят plantuml.com (август 2026); на app.diagrams.net, mermaid.live, lucidchart.com бесплатный просмотр закрылся лимитом (не обходился). Визиты app.diagrams.net, eraser.io, mermaidchart.com — из первой выгрузки ЛР1 без скриншота. Выборка 4 домена (< 5).
- Белстат (студенты, цифровая экономика, ППС, зарплата), НБРБ (3,0285 BYN за USD на 30.09.2026), цены конкурентов (Miro, Lucidchart, Mermaid Chart, Visual Paradigm, Creately, Eraser, Whimsical, dbdiagram.io, Visio), ПВТ, интернет-проникновение.
- Маркетплейсы: VS Marketplace (102 расширения, 20 млн установок), JetBrains (13 плагинов, 9,3 млн загрузок), Capterra, Atlassian, GitHub, npm; G2 и Chrome Web Store недоступны (403, страница согласия) — не обходились.

- make_figures.py — 13 рисунков; build_report.py, rep_*.py — сборка отчёта (таблицы берут числа из Excel-копий).

## Оговорки
- Доля Беларуси в трафике Similarweb — допущение (9,07 % России у plantuml.com × отношение запросов РБ/РФ в Вордстате); результат сильно зависит от него.
- Конверсия Free → Pro, К1–К5, доля дохода на подписки, экономия времени, срок удержания — допущения проекта (шкалы методик для услуг для freemium неприменимы); без опроса их надёжность низкая.
- Клиентские методы (ПК, ПЛ, СВ снизу вверх) согласуются по построению (общие сегменты и коэффициенты); независимую проверку дают только расчёты по трафику и поиску, они значительно ниже.
- При изменении допущений часть пояснительных фраз в текстах листов и отчёта (числа в прозе) нужно сверить вручную: таблицы и числа пересчитываются автоматически, отдельные формулировки записаны словами.

## 3. Общая логика по инструкции (ИНСТР)

### 3.1. Главный принцип

Объём рынка нельзя рассчитывать до фиксации границ рынка [ИНСТР §1]. Для электронного бизнеса учитываются цифровые следы спроса: запросы, посещаемость конкурентов, источники трафика, маркетплейсы, платформы, заявки, продажи, повторные покупки, стоимость привлечения [ИНСТР §1].

### 3.3. Базовые формулы методик [ИНСТР §7]

| Методика | Формула |
|---|---|
| «Сверху вниз» | объём = общий показатель × доля территории × доля сегмента × доля цифрового канала × доля релевантного спроса [§7.1]. Исходный показатель: число организаций в отрасли, общий объём цифровой рекламы, оборот электронной торговли, число пользователей или отраслевой отчёт [§7.1]. **Не от ВВП** — ВВП в перечне нет (З-12) |
| «Снизу вверх» | объём = количество потенциальных клиентов × частота покупки × средний чек [§7.2] |
| Потенциальные клиенты | платёжеспособный рынок = клиенты в сегменте × доля нуждающихся × доля готовых покупать онлайн × средний годовой чек [§7.3] |
| Поисковый спрос | выручка = коммерческая частотность × доля переходов × конверсия в заявку × конверсия в продажу × средний чек [§7.4] |
| Цифровая воронка | выручка = охват × доля переходов × конверсия в заявку × конверсия в оплату × средний чек; для повторных — частота или годовая ценность клиента [§7.5] |
| Маркетплейсы и платформы | GMV = сделки × средняя сумма; выручка платформы = GMV × комиссия [§7.6] |

### 3.4. Последовательность для типа бизнеса [ИНСТР §9 табл. 13]

| Тип | Последовательность | Главный расчёт |
|---|---|---|
| Профессиональная онлайн-услуга | границы → ядро → поисковый спрос → потенциальные клиенты → воронка → платёжеспособность → сценарии | клиенты × доля нуждающихся × средний годовой чек |
| Интернет-магазин | границы → маркетплейсы и конкуренты → Similarweb → поисковый спрос → воронка → сценарии | покупатели × покупок в год × чек |
| Цифровая платформа | границы многостороннего рынка → обе стороны → маркетплейсы/платформы → Similarweb → GMV → комиссия → сценарии | GMV × комиссия |
| Онлайн-образование | границы → поисковый спрос → конкуренты → воронка → платёжеспособность → сценарии | лиды × конверсия в оплату × цена курса |
| Медиапроект | границы аудитории → Similarweb → поисковый спрос → каналы → рекламная модель → сценарии | трафик × монетизация |
| B2B-сервис | границы → число потенциальных клиентов → Similarweb конкурентов → воронка → платёжеспособность → сценарии | компании × доля готовых купить × годовой чек |

NotaCode (freemium-подписка Free / Pro для студентов, аналитиков, архитекторов, преподавателей) прямо ни в одну строку не попадает. [ПРИНЯТОЕ РЕШЕНИЕ В-3]: последовательность «B2B-сервис» с единицей клиента «пользователь», в воронке — модель «Подписка» [ЦВ §9 табл. 8: платящие пользователи × ежемесячный платёж × срок удержания].

### 3.5. Сводная матрица результатов [ИНСТР §10 табл. 14]

Заполняется обязательно, 10 блоков: границы рынка; поисковый интерес; динамика; Similarweb; расчёт сверху вниз; расчёт снизу вверх; цифровая воронка; платформенная модель; платёжеспособность; сценарии. Колонки: «Блок | Что должно быть заполнено | Как используется в итоговом выводе». Форма — §13.1.

### 3.6. Правила согласования [ИНСТР §11]

1. «Сверху вниз» значительно больше «снизу вверх» → проверить коэффициенты сужения и границы.
2. Поисковый спрос высокий, платёжеспособность низкая → уточнить цену, сегмент, формат.
3. Трафик конкурентов в Similarweb высокий, поисковый спрос низкий → проверить рекламу, соцсети, приложения, прямой трафик.
4. Воронка даёт малый объём при большом рынке → проблема в канале, конверсии или стоимости клиента, а не в ёмкости.
5. Сценарии сильно различаются → собрать данные по конверсиям, ценам, конкурентам, сегментам.
6. Итог — диапазон, а не одно число, если данные оценочные.

### 3.7. Типовые ошибки выбора методики [ИНСТР §14 табл. 15]

Считать объём без границ; GT как абсолютный объём; **складывать GT и Вордстат**; трафик конкурентов принимать за продажи; один метод расчёта; не проверять платёжеспособность; не делать сценарии.

### 3.8. Источники ИНСТР [ИНСТР §15 табл. 16, приложение]

Google Trends Help (FAQ), Яндекс Вордстат, Similarweb Data Methodology, European Commission Market Definition Notice, официальная статистика и отраслевые отчёты, рекламные кабинеты и собственная аналитика.

## 5. Методика через поисковый спрос (ПС, ПС-X)

**Правило:** поисковый спрос не равен полному объёму рынка; это цифровое проявление интереса, один из источников оценки [ПС табл. 2]. Применяется после фиксации границ [ПС §2].

### 5.1. Обязательный порядок [ПС §23 табл. 27]

Границы → ядро → классификация по намерению → данные GT → данные Вордстата → очистка и взвешивание → воронка → сценарии → проверка конкурентной среды → вывод.

### 5.2. Семантическое ядро и веса [ПС §5 табл. 8, §6 табл. 9]

Группы: общие тематические, проблемные, коммерческие, инструментальные, региональные, сравнительные, исключаемые.

| Намерение | Вес коммерческой близости |
|---|---|
| Информационный | 0,10–0,30 |
| Проблемный | 0,30–0,60 |
| Инструментальный | 0,50–0,80 |
| Коммерческий | 0,80–1,00 |
| Регионально-коммерческий | 0,90–1,00 |
| Нерелевантный (работа, обучение) | 0,00 |

Вес — экспертный коэффициент, фиксируется и обосновывается [ПС §6]. Коэффициент релевантности 0,70–1,00; региональный 0,50–1,00 [ПС §10 табл. 14].

### 5.3. Сбор данных [ПС §7–§9]

- GT: территория, период (12 мес. — оперативно, 5 лет — сезонность), категория, сравнение 3–5 запросов, CSV, регионы и связанные запросы [ПС §7, табл. 10].
- Вордстат: авторизация; все группы ядра; регион, устройство; вкладки «Динамика», «Регионы», «Топы»; CSV; операторы [ПС §8 табл. 11].
- Очистка: дубли, нерелевантные, намерение, единый период, единый регион, отметка источника [ПС §9 табл. 12].
- GT — для тренда (среднее начала/конца, скользящее среднее), сезонности (месяцы между годами), разовых всплесков, регионов; при наличии только GT — для сезонных коэффициентов, не для объёма [ПС §10, §13 табл. 18].
- География и конкурентная выдача — ПС §14 табл. 19, §15 табл. 20.

### 5.4. Формулы Word [ПС §10 табл. 13, §11 табл. 15]

(1) Взвешенный спрос = частотность × коэф. релевантности × коэф. коммерческой близости × региональный коэффициент.
(2) Переходы = взвешенный спрос × доля переходов; (3) заявки = переходы × конверсия в заявку; (4) продажи = заявки × конверсия в оплату; (5) месячная выручка = продажи × средний чек; (6) годовой объём = сумма месячной выручки (при сезонности) или месячная × 12.

Сценарные ориентиры [ПС §12 табл. 17]: доля переходов 2–4 / 5–8 / 9–12 %; конверсия в заявку 1–2 / 3–5 / 6–8 %; в оплату 10–20 / 25–35 / 40–50 %; чек — нижняя граница рынка / среднее у конкурентов / сегмент высокой ценности.

Рабочая таблица по каждому запросу [ПС §16 табл. 21]: Запрос | Группа | Источник | Регион | Частотность / индекс | Вес коммерческой близости | Коэффициент релевантности | Взвешенный спрос | Комментарий (строки GT — «не считать как объём, использовать для динамики»).

## 6. Методика через цифровую воронку (ЦВ, ЦВ-X)

**Правило:** воронка не измеряет рынок напрямую; оценивает достижимый объём [ЦВ табл. 1]; итог — диапазон [ЦВ §1].

### 6.1. Формулы Word [ЦВ §5 табл. 5, §10 табл. 9]

Visits = Reach × CTR; Leads = Visits × CR1; Sales = Leads × CR2; Revenue = Sales × AOV; Annual = Monthly × 12 (при стабильной или сезонно скорректированной динамике).
Платформа: GMV = сделки × средняя сумма; комиссионная = GMV × комиссия; подписочная = платящие × стоимость подписки; рекламная = показы × ставка / 1000; смешанная = сумма.
Модели по типам бизнеса [ЦВ §9 табл. 8]: цифровая услуга; интернет-магазин; онлайн-курс; платформа услуг; рекламная; **подписка: платящие пользователи × ежемесячный платёж × срок удержания**.

### 6.2. Порядок [ЦВ §6]

Границы → тип модели → данные аудитории → **разделить каналы** (поиск, реклама, соцсети, прямые, рефералы, маркетплейсы, рассылки, партнёрства) → **для каждого канала** переходы, заявки, продажи, выручка → конверсии по трём сценариям → сложить по каналам → сопоставить с конкурентами, Similarweb, поисковым спросом, «снизу вверх» → диапазон и ограничения.

Таблицы Word: входные данные [ЦВ §7 табл. 6]; расчёт по каналам [ЦВ §8 табл. 7: органический поиск, платная реклама, соцсети, переходы с платформ, реферальный, прямые]; сценарии [ЦВ §11 табл. 10–11]; проверка надёжности [ЦВ §13 табл. 14]; ошибки [ЦВ §14 табл. 15]; итоговый шаблон [ЦВ §15]; рабочий паспорт из 11 полей [ЦВ §16 табл. 16]; источники [ЦВ §17 табл. 17].

## 7. Методика через маркетплейсы и платформы (МП)

Excel-шаблона нет. Итог — диапазон; отдельно SOM или первый достижимый сегмент [МП §1, §13 табл. 15].

### 7.1. Типы рынков и модели [МП §2 табл. 2, §9 табл. 11]

Типы: товарный маркетплейс, площадка услуг, платформа специалистов, образовательная платформа, агрегатор/каталог, **приложение или сервис (установки, рейтинг, отзывы, место в категории, платные планы → потенциал рынка цифровых подписок и приложений)**.
Модели: через отзывы (продажи = отзывы / коэф. отзывов); через активных продавцов; через трафик (продажи = трафик × конверсия); через заказы; через подписку (платящие × тариф × период); через комиссию (GMV × комиссия).

### 7.2. Формулы [МП §5–§8]

Объём категории = оценённые продажи × средняя цена; продажи = отзывы / доля оставляющих отзыв; оборот услуг = заказы × чек × повторяемость; GMV, выручка платформы, подписка, реклама, смешанная [МП табл. 9]; релевантный трафик платформы = посещаемость × доля географии × доля категории/раздела × доля коммерческого намерения [МП §8].

Сценарии [МП §11 табл. 13]: коэффициент отзывов 10 / 5 / 2 %; конверсия трафика в заказ 0,5 / 1,5 / 3 %; доля активных предложений 30 / 50 / 70 %; чек — нижний квартиль / медиана / верхний квартиль; доля географии — мин. / средняя / макс. (W-17: осторожный коэффициент отзывов 10 % даёт меньше продаж).

### 7.3. Что заполнить

- Журнал: дата, площадка, категория, регион, ссылка, запрос, период наблюдения [МП §3].
- Таблица сбора по площадкам [МП §10 табл. 12]: Площадка | Категория | География | Ед. наблюдения | Предложений | Активных продавцов | Средняя цена | Отзывы | Оценка заказов | Источник.
- Проверка надёжности [МП §13 табл. 15]: с поисковым спросом, Similarweb, ценами на сайтах конкурентов; «через отзывы» против «через трафик» — порядок величины.
- Ошибки [МП §14 табл. 16]; итоговый шаблон [МП §15].

## 8. Проверка через платёжеспособность (ПЛ, ПЛ-X)

Платёжеспособный спрос = потребность × готовность платить × финансовая возможность × доступность покупки; возникает при 4 условиях одновременно: проблема, признание ценности, финансовая возможность, эффект оправдывает затраты [ПЛ §1 табл. 2].

### 8.1. Формулы Word

- (1) Платёжеспособные клиенты = потенциальные × Kпотребности × Kфинансовой возможности × Kготовности платить × Kцифровой доступности [ПЛ §6 табл. 6–7].
- (2) Допустимый средний чек = min(рыночный ценовой коридор; бюджет клиента; экономически оправданная цена) [ПЛ §7 табл. 9].
- (3) Коэффициент оправданности = ожидаемый экономический эффект / стоимость решения; шкала: <1 — слабо обоснована; 1–2 — может быть оправдана, чувствительность к цене; 2–5 — разумна, базовый сегмент; >5 — высокий эффект, премиальный тариф [ПЛ §8 табл. 10–11].
- B2B [ПЛ §9 табл. 12]: годовой бюджет = выручка клиента × допустимая доля расходов; доля затрат = стоимость / выручка; окупаемость = стоимость / доп. месячная прибыль; порог покупки; LTV = чек × месяцы сотрудничества.
- B2C [ПЛ §10 табл. 13]: доля цены в месячном доходе; доля цены в располагаемом бюджете; частота покупки; ценовая чувствительность; порог массовости.
- Денежный объём [ПЛ §12 табл. 15–17]: платёжеспособные клиенты × чек × частота; услуги — × годовой бюджет на услугу; платформа — GMV и GMV × комиссия.
- Уровни ценового коридора [ПЛ §7 табл. 8]: минимальная, средняя, высокая, цена заменителя.
- Разделение интереса и спроса [ПЛ §5 табл. 5]: информационный — нет; проблемный — частично; коммерческий — да (проверить цену); поведенческий — да, если есть действие; фактический — да.

## 11. «Сверху вниз» и «снизу вверх» с Similarweb (СВ, СВ-X)

Два взаимодополняющих расчёта и их согласование [СВ §1 табл. 3]; итог — диапазон, проверенный двумя подходами [СВ табл. 4].

### 11.1. Word: «сверху вниз» [СВ §3 табл. 7–12]

Шаги: границы → **10–20 сайтов** → месячные посещения → география → очистка от нерелевантного → учёт неполноты списка → перевод в деньги.
(1) видимый трафик = Σ посещений конкурентов; (2) релевантный по географии = видимый × доля страны; (3) оценочный трафик = релевантный / коэффициент покрытия (покрытие 70 % ⇒ 0,70); (4) объём = оценочный трафик × конверсия в покупку × чек × число периодов в году. Коэффициенты: доля географии, релевантности, **покрытия 0,5 / 0,7 / 0,9**, CR1, CR2, чек.

### 11.2. Word: «снизу вверх» [СВ §4 табл. 13–17]

(5) услуги: посещения × доля коммерческого трафика × CR1 × CR2 × чек; (6) интернет-магазин: посещения × конв. в заказ × чек × повторы; (7) платформа: GMV, выручка = GMV × комиссия; **подписной сервис: посещения × регистрация × оплата × средний период удержания** [табл. 17]; медиа.

### 11.3. Совмещение и итог [СВ §5 табл. 18–19]

Четыре ситуации (сверху ≫ снизу; снизу ≫ сверху; сопоставимы; обе низкие). Итоговая оценка = [минимум из осторожных; максимум из проверенных базовых/оптимистичных].
Рабочие таблицы [СВ §7]: карточка источника Similarweb (9 полей), таблица «сверху вниз», таблица «снизу вверх» по каналам (органический, платный поиск, соцсети, рефералы), сценарная таблица (покрытие 0,5 / 0,7 / 0,9). ## 12. Similarweb: бесплатный доступ, объём рынка, концентрация (SWБ, М1, М2, SW-X)

### 12.1. Бесплатный доступ [SWБ]

Бесплатный Similarweb — разведочный анализ; любой количественный вывод — диапазон с источниками и ограничениями; не показанный показатель не домысливать — «нет данных в бесплатном доступе» [SWБ правило, §1]. Полные выгрузки, Data Exporter, API/Batch API, автоотчёты, глубокая история, массовый анализ — недоступны; выборка 5–15 доменов; автоматическое извлечение без прав может нарушать условия — работать вручную [SWБ §2 табл. 3, §14]. Для доказательности — скриншот или PDF страницы [SWБ §5].
Таблицы: типы сайтов для выборки [§4 табл. 5]; карточка сайта (6 полей) [табл. 6]; **журнал ручной фиксации**: Дата | Домен | Период в Similarweb | Страна/география | Показатель | Значение | Единица | Комментарий [§5 табл. 7]; минимальный набор показателей (9) [§6 табл. 8]; доли по трафику [§7 табл. 9]; оценка сегмента через трафик и конверсию (релевантная доля 20–60 %, заявка 0,5–3 %, продажа 10–30 %) [§8 табл. 10–11]; каналы [§9 табл. 12]; география [§10 табл. 13]; итоговая таблица из 10 колонок [§12 табл. 16]; шаблон итоговой оценки [§13 табл. 17]; ошибки [§14]; чек-лист (8) [§15].
Формула: цифровая доля сайта в выборке = посещения сайта / сумма посещений выборки × 100 %; если по малым сайтам данных нет — «доля видимого трафика среди сайтов, по которым доступны данные», не «доля рынка» [SWБ §7].

### 12.2. М1 — объём рынка по данным Similarweb

- Схема из 10 шагов, шаг 7 — **суммарный трафик, доли игроков, CR3/CR5 и HHI** [М1 §4 табл. 3].
- Выгрузки: интерфейс (XLSX, CSV, PDF, PNG, ссылка), Data Exporter, REST API, Batch API, Data Feeds, Scheduled reports, модули e-commerce; фиксировать способ выгрузки [М1 §5 табл. 4–7].
- Матрица из 14 показателей (Total Visits … Category Share) [М1 §6 табл. 8].
- Формулы [М1 §7]: (1) объём цифрового трафика = Σ визитов набора; (2) доля сайта = визиты / суммарные × 100 %; (3) SAM по трафику = суммарные визиты × доля страны; CR3, CR5; **HHI = сумма квадратов долей в процентах**; «концентрация цифрового внимания/трафика», не выручки; три качественных уровня [табл. 10]; канальный SAM = трафик рынка × доля канала × достижимая доля в канале; потенциальная выручка из поиска = коммерческие поисковые визиты × достижимая доля × CR1 × CR2 × чек; выручка = трафик × достижимая доля × CR1 × CR2 × чек × число покупок за период.
- Сценарии [М1 §7.5 табл. 13]: достижимая доля трафика 0,1–0,5 / 0,5–2 / 2–5 %; CR1 0,3–1 / 1–3 / 3–7 %; CR2 5–15 / 15–30 / 30–50 %; чек — низкая / реалистичная / верхняя; повторы — нет / частично / регулярно.
- Порядок [М1 §8]: период **не менее 12 месяцев** (сезонные 24–36); единые страна, устройство, тип трафика; Website Analysis → Traffic & Engagement → Geography → Marketing Channels → Search → Referrals → Social → Demographics → Category; единое именование файлов [табл. 14].
- Рабочие таблицы [М1 §9]: паспорт анализа (10 полей) [табл. 15]; конкурентный набор [табл. 16]; трафик и доли [табл. 17]; каналы с Email [табл. 18]; поисковый спрос с CPC [табл. 19]; журнал выгрузок [табл. 20].
- **Итоговая модель [М1 §11 табл. 22]:** TAM цифрового внимания = суммарный трафик релевантных сайтов категории; SAM по географии = TAM × доля страны; SAM по каналу = SAM × доля релевантных каналов (поиск, рефералы, соцсети, платная реклама); SOM по трафику = SAM × достижимая доля; SOM по выручке = достижимый трафик × конверсия × чек × частота; проверка конкурентами = средняя выручка конкурента × число активных конкурентов; проверка поиском.
- Контроль [М1 §12, 10 вопросов — раздел 16]; ошибки [§13 табл. 23]; шаблоны формулировок [§14.1–14.4]; источники [§15, 12 статей]; итоговый алгоритм [§16].

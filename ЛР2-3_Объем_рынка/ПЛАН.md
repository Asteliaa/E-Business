# ЛР2-3 — план выполнения

Работа объединяет вторую и третью лабораторные (объём рынка; Similarweb). Последовательность — по инструкции применения методик (ИНСТР §2): границы → поисковый спрос → Similarweb → «сверху вниз» / «снизу вверх» → потенциальные клиенты → воронка → маркетплейсы → сценарии → платёжеспособность → сведение.

## Принципы
- Строго по методичкам и Excel-шаблонам; где Word и Excel расходятся, основной расчёт — по Excel, рядом по Word, расхождение названо.
- Явные поломки шаблонов исправляются только в рабочих копиях и описываются (приложение Г).
- Чего нет в открытом доступе — «🔲 ДОСНЯТЬ: что / где / как» (приложение Б).
- Допущения проекта собраны в одном журнале (Python\assumptions.py, приложение Б); изменение значения и повторный запуск скриптов пересчитывают книги и отчёт.

## Порядок повторной сборки после изменения допущений
1. Правка значений в Python\assumptions.py / Python\inputs.py.
2. Запуск fill_ps → fill_cv → fill_pl → fill_pk → fill_sv → fill_sc → fill_sw (порядок важен: ЦВ и СЦ читают результаты ПС и ПК).
3. calc_all.py → make_figures.py → build_report.py → _tools\build_lab_docx.py ЛР2.
